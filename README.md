Sb2 - Modern Web-Based Text Editor

Sb2 is a lightweight, feature-rich, and customizable text editor built for modern web development. It supports multiple programming languages, syntax highlighting, and a sleek dark theme, optimized for both desktop and mobile environments.


---

Features

Syntax Highlighting: Supports JavaScript, Python, HTML, and CSS.

Customizable Themes: Includes dark theme.
WIP

File Operations: Create, open, and save files seamlessly.

Keyboard Shortcuts: Boost productivity with pre-configured shortcuts.

Dark Mode: Default dark theme for an ergonomic coding experience.

Responsive Design: Works seamlessly on both desktop and mobile.



---

Installation

1. Clone the Repository:

git clone https://github.com/Sneaking/sb2.git
cd sb2


2. Install Dependencies: Ensure you have Node.js and npm installed. Then run:

npm install


3. Start the Development Server:

npm run dev


4. Access the Application: Open your browser and navigate to or other port Vite suggests:

http://localhost:3000



---

How to Use

1. Start Coding:

Open the editor in your browser.

Begin typing directly or load an existing file using the file menu.



2. Switch Language:

Use the dropdown in the header to select a programming language (JavaScript, Python, HTML, or CSS).



3. Keyboard Shortcuts:

Shift+S: Save the file.

Shift+N: Create a new file.

Shift+C: Toggle the chat assistant.

Shift+I: Activate code completion.
(WIP) + Needs api key




4. Custom Themes:

Modify the theme in the config.js file if needed.



5. File Operations:

Use the "Open" or "Save" options to manage your files.
